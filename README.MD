## DISCLAIMER
This is a purely passion-driven project for non-commercial use with open-source emulated cores.
Constructive criticism is welcome
### Functionality
Randomizes a myriad of WoW's features, including but not limited to:
- Creatures (Mobs, Vendors, Trainers, etc.) that spawn within a zone
- Zones will split into level brackets and populate with its respective mobs
- Player attributes (Spells, skills, exp, etc.)
- Spawn location

### (Planned) Features
- Fully customizable config with options to change the randomizer
- Custom modes
- In-game tracker with goals
- Script to simplify process
- ...and more (maybe!)
